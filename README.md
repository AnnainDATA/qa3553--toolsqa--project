# 🧪 Practice Form Automation
### 🚀 Test Automation Project

This project is my attempt to automate the **Practice Form** page from [DemoQA](https://demoqa.com/automation-practice-form).
The automation was written in **Python** using **Selenium**.
The main goal of the project was to practice UI automation and check that the form can be filled in and submitted correctly.
